Starfall Arena is an original neon twin-stick arena survival shooter for the browser: pilot a lone starfighter against escalating waves of six enemy types and the three-phase Voidherald boss, draft one of three upgrades between waves, chain kills into combo multipliers, and chase your best score. Plain JavaScript and Canvas — no libraries, no build step, no network; every visual is drawn in code and every sound is synthesized with WebAudio.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
# WASD/arrows move, mouse aims, click/hold fires, Space dashes, P pauses
```
